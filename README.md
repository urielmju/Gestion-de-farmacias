Sistema web de gestión farmacéutica desarrollado con ASP.NET MVC 5, C# y SQL Server. Permite administrar de forma integral las operaciones de una farmacia, incluyendo gestión de inventario, registro de compras y control de ventas.
ASP.NET MVC 5
C#
Entity Framework (Database First)
SQL Server
Bootstrap
Gestión de inventario de productos
Registro y seguimiento de compras
Control de ventas
Administración de proveedores y clientes
